ROYAL OASIS HOTEL & RESORT — Student Project
================================================
Built with HTML and CSS only. Arabic + English content.

HOW TO RUN
1. Extract the ZIP.
2. Open the royal-oasis-resort folder in VS Code.
3. Open index.html in your browser, or use the Live Server extension.
4. Use the top navigation to visit all six pages.

FILES
- index.html       Home page
- rooms.html       Rooms & Suites
- facilities.html  Facilities & Services
- experiences.html Experiences & Offers
- gallery.html     Photo gallery
- contact.html     Contact and demo booking form
- css/style.css    Shared styles and responsive layout

NOTES
- Photos are loaded from Unsplash, so an internet connection is needed for them.
- Google Fonts are imported online.
- Prices, address, phone and email are illustrative demo content.
- The booking form is frontend-only and does not submit to a real reservation system.
- This project uses HTML/CSS only; no JavaScript.
